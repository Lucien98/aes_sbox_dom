# Masked AES S-Box using Domain-Oriented Masking

This repository contains the Verilog implementation of S-Box constructions presented in our paper:  
**_Domain-Oriented Masking Revisited: More Efficient AES Implementations with Arbitrary Protection Order_**.

Our work builds upon [aes_dom](https://github.com/hgrosz/aes-dom), while providing **formally proven security** under the **glitch-extended probing model**.

To reproduce the results presented in the paper, please refer to [MaskedAES](https://github.com/Lucien98/MaskedAES).
